      💾 Backup e Restauração de Dados (JSON)
      
          
      
            Como o sistema utiliza exclusivamente o LocalStorage do seu navegador, recomendamos exportar backups regularmente para evitar perda de dados ao limpar o cache.
          
      

          
      
            
      
              
      📤 Exportar Dados
      
              
      Baixe um arquivo .json contendo todas as anotações, categorias, destinatários e históricos.
      
              
            
      

            
      
              
      📥 Importar Dados
      
              
      Restaure um backup .json anterior. Os registros serão mesclados ou restaurados com validação.
